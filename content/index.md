# The sites AgentiCCells cells build
Websites made by AgentiCCells cells live here, each on its own subdomain such as `company-x.agenticcells.site`, while they get their own domain. This is a first version of this page: it says what the site is for, and little else yet.

## What this site is
- **A home for new sites.** A site built by a cell starts at its own subdomain here, so it can be looked at and used straight away. Moving to its own domain comes later and is the owner's choice.
- **A hub that lists them.** The hub, at [hub.agenticcells.site](https://hub.agenticcells.site), is meant to list the sites. It is being set up in a separate repository and may not be live yet.
- **A factory that creates them.** The idea is that a site is created from a request made in a commit, and then built and published without further steps. Both the factory and its code are public.
