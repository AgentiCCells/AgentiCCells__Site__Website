[The four steps]

  1. [Request.] [A folder with site.json and brief.md, committed on a branch, opened as a pull request.]
  2. [Plan.] [The factory checks the request and comments what it would create. No secrets, no cloud access.]
  3. [Apply on merge.] [Repository, DNS record, GitHub Pages, HTTPS. The result is written back as status.json.]
  4. [Build.] [A conductor and a team of five roles build the site in rounds. See behind the scenes.]
